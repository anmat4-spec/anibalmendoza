## Cómo descargar

**Todo junto:** en la página principal del repositorio, pulsa **Code** y después **Download ZIP**. Descomprime el ZIP y abre la carpeta `entregables`.

**Un archivo:** abre su enlace y pulsa **Download raw file** (icono de descarga) en la página del archivo. Si GitHub no puede mostrar una vista previa, utiliza igualmente la descarga.

## Alcance técnico

Los documentos contienen una revisión técnica y un predimensionamiento para postes de madera tornillo, adoptando datos del Anexo 2 entregado. Las dimensiones son preliminares: requieren validación del ingeniero responsable antes de ejecutar. No constituyen certificación de capacidad dinámica del sistema ni autorización de trabajos simultáneos expuestos.
